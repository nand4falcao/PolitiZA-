# PolitiZA! — protótipo web

Site demonstrativo em React + TypeScript + CSS, com páginas de início, mapa, detalhes de atos, notícias, login, área do usuário, cadastro demonstrativo e painel administrativo.

## Executar
1. Instale Node.js e pnpm.
2. No terminal, dentro desta pasta, execute `pnpm install`.
3. Execute `pnpm run build`.
4. Execute `pnpm run serve`.
5. Acesse http://localhost:8080.

## Observações
- Os eventos e notícias são dados fictícios para demonstrar o layout.
- Login, cadastro, verificação e publicação são interações demonstrativas; não há backend, banco de dados nem API conectados.
- O mapa é uma representação visual ilustrativa, não um mapa geográfico real.
- Para produção, será necessário integrar serviços reais de mapas/geolocalização, notícias, autenticação e persistência de dados.
